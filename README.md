# Trade Shield Pro

Flutter starter project based on the requested project structure.

## Build APK

1. Install Flutter SDK.
2. Run `flutter pub get`.
3. Run `flutter build apk --release`.
4. APK will be generated under `build/app/outputs/flutter-apk/app-release.apk`.

## Important

This project is a functional starter UI and risk calculator. It does **not** connect to a broker or place real trades. API/broker integration must be implemented and tested separately.
